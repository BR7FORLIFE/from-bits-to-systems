## Proyecto 0 — Simulación del Tiempo y la Memoria

Objetivo:
Comprender cómo existían la memoria y el tiempo antes de los lenguajes de programación.

Qué hace este proyecto:

* Simular un reloj
* Simular un biestable
* Mostrar cambios de estado explícitamente
* Hacer visible el tiempo

Reglas:

* No usar abstracciones por conveniencia
* No simular que las cosas son instantáneas
* Cada cambio ocurre en un tic

Esto no es un programa. Es un modelo mental ejecutable.


ROADMAP ANTERIOR PARA ESTUDIAR FLIP FLOPS Y CLOCK
Puertas lógicas → Combinacionales → Secuenciales → Flip-flops → Reloj → Simulaciones → C
